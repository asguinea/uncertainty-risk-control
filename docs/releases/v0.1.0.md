# v0.1.0 — GoEmotions risk-control research

This first research release makes the GoEmotions MB1 final-calibration procedure replayable from published sufficient statistics and regenerates its aggregate tables and figures. It also includes the reusable exact-binomial fixed-sequence method, synthetic verification, and a small teaching example.

The main empirical finding is the distinction between passing calibration and useful automation. On the study's 10,853 locked comments, the 5% and 10% risk-budget policies accept only 3.86% and 4.88% respectively. The [research note](../research-note.md) explains the trade-off, calibration sample-size effects, annotation-consensus differences, descriptive baselines, and unsuccessful development steps.

## Included in this release

- Final-calibration replay of all 35 executed tests across four separately calibrated budgets, including each first failure. The 21-candidate sequence is preserved; the unexecuted tail is not explored.
- Locked counts, baselines and subgroup summaries, plus 2,804 warm-up aggregate records and regenerated sample-size summaries.
- Two scientific figures in SVG/PNG, their numerical inputs and generator, exact source/evidence hashes, protocol documentation, and citation/license scope.
- Cross-platform checks for isolated wheel installation, the unit suite, all 150,000 prescribed synthetic verification trials, replay, tables and figures.

The [reproduction contract](../../experiments/goemotions/reproduction.md) defines the boundary. This release does not provide historical retraining, checkpoint inference, or reconstruction of warm-up sample orders and candidate prefixes. It distributes no raw comments, original row-level exports, identity keys, model weights, or EyeTrustAI product runtime.

Download the source distribution and compare its SHA-256 with `SHA256SUMS` before extracting it. Alternatively, clone the versioned Git tag:

```sh
git clone --branch v0.1.0 https://github.com/asguinea/uncertainty-risk-control.git
cd uncertainty-risk-control
uv sync --locked
uv run --locked python examples/selected_risk_walkthrough.py
uv run --locked uqrc goemotions --evidence experiments/goemotions/evidence --output results/goemotions/replay.json --report results/goemotions/tables.md
```

See the [reproduction guide](../reproduction.md) for plotting and synthetic commands, and the [verification guide](../verification.md) for the isolated wheel/source-archive checks. Dependency installation may require internet access. The installed study replay needs no raw dataset download or model.

## Interpretation and attribution

The error indicator concerns whether an accepted top tag belongs to the complete set of labels supported by at least two recorded raters. It measures agreement with that reference, not psychological truth. The locked role is the study's own group-preserving split, not the official GoEmotions test split.

Each risk budget uses delta 0.05 separately under the [method's sampling and protocol assumptions](../method.md#assumptions-and-interpretation). There is no simultaneous four-budget or subgroup guarantee. Grouping reduces obvious leakage but does not establish independent Bernoulli observations. Warm-up frequencies and percentile bands describe reused development evidence; they are not independent replications or confidence intervals. CI checks arithmetic and reproducibility, not those sampling assumptions or product readiness.
